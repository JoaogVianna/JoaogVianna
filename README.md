### <img src="https://img.shields.io/badge/%E2%9C%A6-Sobre%20mim-7C3AED?style=for-the-badge&labelColor=171329" />

Olá! 👋 Sou **João Gabriel**, desenvolvedor **Full Stack** do Rio de Janeiro, apaixonado por tecnologia e pela criação de soluções digitais.

Trabalho com desenvolvimento **Front-end e Back-end**, construindo interfaces modernas, APIs REST e integrações com bancos de dados. Também exploro o desenvolvimento mobile e busco aprimorar minhas habilidades por meio de projetos práticos.

- 🚀 **Desenvolvimento:** React, Next.js, TypeScript, Java e Spring Boot
- 📱 **Mobile:** React Native e Expo
- ⚙️ **Back-end:** Node.js, Express e APIs REST
- 🗄️ **Banco de dados:** PostgreSQL e Supabase
- 🐧 **Ambiente:** Linux, Git, GitHub e terminal
- 🎯 **Objetivo:** evoluir como desenvolvedor Full Stack e criar soluções eficientes, escaláveis e bem estruturadas
